# Phoolbari (फूलबारी) — Nepal's Online Flower Shop

A responsive, SEO-optimized Nepali flower shop and Daraz-style e-commerce web application built with **HTML5, CSS3, and Vanilla JavaScript**.

## Features
- **20+ Nepali & Popular Flowers**: Sayapatri (सयपत्री), Makhamali (मखमली), Laligurans (लालीगुराँस), Godavari, Chameli, Parijat, Kamal, Surya Mukhi, Beli, Mandar, plus Red Roses, Peonies, Lilies, Tulips, Orchids, Hydrangea, Carnations, Baby's Breath, Gerbera, and Wedding Bouquets.
- **Daraz-Style E-Commerce Experience**: Live search suggestions, category & budget filters, sorting, wishlist, quick-view modal, item-selectable cart, promo codes (`PHOOL10`, `TIHAR50`), eSewa/Khalti/Fonepay/COD checkout, and 4-step live order tracking.
- **Live Current Location Shop Pin**: Interactive Leaflet map with one-click GPS detection (`navigator.geolocation`) to pin the Phoolbari Express Hub at your current location and auto-fill checkout addresses.
- **SEO Optimized**: Semantic HTML5, Open Graph & Twitter Cards, JSON-LD (`Florist` + `FAQPage`), `robots.txt`, and `sitemap.xml`.
